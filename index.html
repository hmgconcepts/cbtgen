Questions people ask

Is this the same as the HMG CBT exam platform?

No — and by design. This site is the generator: it builds CBT platforms for clients. The thing it builds (and the thing your students, teachers and admins use) is the separate CBT system. The generator contains no exam portals and no logins; the generated system contains no generator. Deploy them as separate sites.

Does it need a server, build step or paid API?

No to all three. The generator is static HTML + JS (deploy the folder to Vercel, Netlify, Cloudflare Pages or GitHub Pages). Branding and ZIP packaging happen entirely in the browser via JSZip. The generated platform uses Supabase's free tier and deliberately ships with no AI API — its prompt studio produces copy-paste prompts for free AI chats instead.

What do I set up before the client's package works?

One thing: a free Supabase project for the client. Create it, run database/complete-schema.sql once in the SQL Editor, and paste the project URL + anon key into Step 3 of the wizard. The generator tests the connection live before packaging.

How is the client's licence handled?

Choose lifetime or subscription (cycle, expiry date, grace days) in Step 3. The licence is baked into the package as an offline HMAC-SHA256 certificate bound to the client's domain — verification needs no phone-home server.

What if a file is missing from the generated ZIP?

You'll know before your client does. After building, the generator re-opens the ZIP and verifies every expected file is present and non-empty; the report lists anything missing and flags whether it was critical. Silent failures are impossible by design.

Note for existing HMG CBT platform users: this generator is a separate product and a separate deployment. If you are looking for the exam platform itself (where students take tests), that is deployed elsewhere — this site only builds platforms.
